# QUADAS-3: diagnostic test accuracy

Version: **QUADAS-3**, Ann Intern Med, 17 February 2026
(doi:10.7326/ANNALS-25-02104), with an Explanation and Elaboration paper
(doi:10.7326/ANNALS-25-04943). It replaces QUADAS-2 for diagnosis, screening and
staging accuracy studies.

Changes from QUADAS-2: judged per **accuracy estimate**, not per study; multiple
synthesis questions; an **ideal test accuracy trial** defined per question to judge
applicability; a formal overall-judgement phase; revised domains and questions.

## Six phases

| Phase | Level |
|-------|-------|
| 1. State the synthesis questions | Review |
| 2. Define the ideal test accuracy trial per question | Review |
| 3. Draw the study's flow diagram | Study |
| 4. Identify the accuracy estimates to assess | Study |
| 5. Assess risk of bias and applicability concerns | Each estimate |
| 6. Overall judgement | Each estimate |

Signalling answers: Yes, Probably yes, Probably no, No, No information.
Risk of bias and applicability levels: **Low**, **High**, **Insufficient information**.
All Y/PY in a domain → Low. Any N/PN flags possible bias; judge it.

## Phase 5 domains

**D1 Participants**
- 1.1 Single-gate design?
- 1.2 Prospective enrolment?
- 1.3 Consecutive or random sample?
- 1.4 Representative of the intended-use population?
- Applicability: do participants match the ideal trial?

**D2 Index test**
- 2.1 Conducted and interpreted as recommended?
- 2.2 Interpreted without knowledge of reference standard results?
- 2.3 Interpreted with the information available in practice?
- 2.4 Threshold standard or pre-specified?
- Applicability: does the test and its conduct match the ideal trial?

**D3 Target condition**
- 3.1 Does the reference standard identify the target condition adequately?
- 3.2 Was the target condition assessed in all participants?
- 3.3 The same way in all?
- 3.4 Reference standard free of the index test (no incorporation)?
- 3.5 Conducted and interpreted as recommended?
- 3.6 Interpreted blind to index test results?
- 3.7 Threshold standard or pre-specified?
- 3.8 Appropriate interval between index test and reference standard?
- Applicability: does the target condition as defined match the ideal trial?

**D4 Analysis**
- 4.1 All participants included in the analysis?
- 4.2 Missing data handled appropriately?
- 4.3 Unit of analysis matches the ideal trial?
- 4.4 Sensitivity and specificity calculated appropriately?
- (No applicability judgement.)

## Where to look

STARD flow diagram, `section: "Methods"` (recruitment, reference standard,
blinding), `query: "2x2"` / `"sensitivity"`, `query: "indeterminate"`.

## Feeds GRADE as

Risk of bias for sensitivity and specificity, rated separately. Applicability
concerns feed indirectness.
