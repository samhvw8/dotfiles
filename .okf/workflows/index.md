# Workflows

* [Set up a new machine](new-machine-setup.md) - Install mise, clone the repository and bootstrap a new macOS or Debian/Ubuntu machine.
* [Change, add and sync dotfiles](everyday-changes.md) - Day-to-day loop: edit through the links, save with dot:save, push, and pull on other machines.
* [Migrate a machine still on chezmoi](migrate-from-chezmoi.md) - Run migrate-from-chezmoi.sh to move a machine from chezmoi to mise dotfiles without losing local changes.
* [Keep ccp hub items](ccp-hub-items.md) - Which parts of ~/.ccp live in the repository and how to store hub items created by hand.
* [Switch zsh plugins and zi to the forks, or roll back](zsh-plugin-forks.md) - How the shell runs patched forks of fzf-tab, F-Sy-H, zsh-autosuggestions and zi, how to switch, roll back and retire them.
* [Troubleshooting](troubleshooting.md) - Symptoms seen with this setup and what to do about them.
